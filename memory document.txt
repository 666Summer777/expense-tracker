Expense Tracker project memory
Last updated: 2026-05-24

Project summary
- This is a small React + Vite Expense Tracker app.
- It is an expense-only tracker. It does not track income.
- It is designed primarily for iPhone Safari "Add to Home Screen" use, behaving like a lightweight mobile app.
- The UI must remain in English.
- Data is stored locally in the browser using localStorage.
- The app is deployed to GitHub Pages under the `/expense-tracker/` base path.

Current branch and status
- Work should continue on `codex/feature/ui-polish`.
- Do not work on `main` unless the user explicitly asks.
- The latest UI direction the user likes is the green iOS-like refresh inspired by a reference screenshot:
  - warm ivory / cream background
  - soft sage / forest green accents
  - white rounded cards
  - subtle shadows
  - gentle contrast
  - clean, premium, iPhone-app feeling
- The user explicitly said they are satisfied with the current green version and may not modify the app for a long time.

Tech stack
- React 19
- Vite
- vite-plugin-pwa
- No backend
- No login
- No cloud sync
- No database
- No external UI library

Important commands
- Run locally: `npm run dev`
- Build production: `npm run build`
- Preview production build: `npm run preview`
- Lint command exists: `npm run lint`

Important files
- `src/App.jsx`
  - Main app component.
  - Contains all expense logic, localStorage loading/saving, backup import/export, delete confirmation state, category constants, SVG icons, and markup.
- `src/App.css`
  - Main visual design file.
  - Controls header, summary cards, budget progress, budget form, add expense form, category chips, expense list, empty state, and delete confirmation dialog.
- `src/index.css`
  - Global reset, body font, background, and base input/button font inheritance.
- `vite.config.js`
  - GitHub Pages base path and PWA configuration.
  - Do not casually modify this.
- `public/manifest.webmanifest` and icon files
  - PWA/Home Screen assets.
  - Do not modify unless the task is specifically about PWA icons/manifest.
- `dist/`
  - Build output generated by `npm run build`.

Data and storage rules
- Do not change the localStorage data structure without explicit user approval.
- Current localStorage keys:
  - `expenses`
  - `budget`
- Expenses are stored as an array of objects similar to:
  - `id`
  - `name`
  - `amount`
  - `category`
  - `date`
- Budget is stored as a month-keyed object, for example:
  - `{ "2026-05": 550 }`
- Import/export JSON expects:
  - `{ expenses, budget }`
- Preserve backward compatibility with the user's existing local data.

Design direction to preserve
- The current accepted UI is green, calm, and iOS-like.
- Header:
  - light cream/green translucent top bar
  - circular leaf badge on the left of "Expense Tracker"
  - pale green circular `...` menu button on the right
- Summary cards:
  - four rounded white cards
  - each card has a soft icon badge:
    - Monthly Budget: wallet icon
    - Spent: down arrow icon
    - Today: calendar icon
    - Remaining: pie/progress icon
  - large, clear numeric values
  - Remaining uses green when positive
  - Spent/danger uses muted coral/red, not bright red
- Budget progress:
  - soft green gradient fill
  - pale green track
  - green percent pill
- Forms:
  - rounded white/cream inputs
  - deep soft green primary buttons
  - category chips are clean rounded bordered controls
- Expense list:
  - white rounded cards
  - subtle category color stripe
  - small category emoji badge
  - muted coral amount color
  - delete button should stay soft and unobtrusive
- Delete confirmation:
  - bottom-sheet style
  - cream/green visual language
  - Cancel and Delete actions remain clear

User preferences and constraints
- Keep the UI English.
- Keep the app simple and minimal.
- Do not add income tracking.
- Do not add login, backend, cloud sync, accounts, database, or App Store-related features.
- Do not over-design or add flashy colors.
- Avoid fancy pastel dopamine colors; the user preferred the calmer green reference.
- Avoid heavy black headers.
- Avoid making it feel like a web admin dashboard.
- Prioritize mobile/iPhone layout.
- Preserve Export JSON / Export CSV / Import JSON.
- Preserve delete confirmation.
- Preserve localStorage data structure.
- Preserve PWA/GitHub Pages config unless the task explicitly targets deployment/PWA.
